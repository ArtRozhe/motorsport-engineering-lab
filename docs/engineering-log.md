# Engineering Log

This log documents meaningful investigations performed while learning motorsport data and performance engineering.

It is not intended to record every coding session.

Create an entry when the work involves a meaningful engineering question, unexpected result, failed assumption, or useful investigation.

Entries are written by me. AI may review the reasoning and the English, but does not edit or generate the content.
