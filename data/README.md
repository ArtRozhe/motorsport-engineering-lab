# Data

Raw datasets are not committed to this repository. Everything in `data/` except this file is gitignored.

Every dataset used in an analysis must be documented below.

## Entry template

### Dataset name

- **Source:** where the data comes from (URL, library, tool).
- **License / terms of use:** what is allowed, in particular redistribution.
- **Retrieved:** date, and library or API version if applicable.
- **How to obtain:** steps or script to reproduce the local copy.
- **Contents:** channels, units, sampling rates, coordinate systems.
- **Preprocessing by the source:** interpolation, resampling, merging, or derived channels applied before the data reaches us.
- **Known limitations:** resolution, gaps, accuracy, anything that constrains conclusions.
